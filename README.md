## Project Info

**D.Verse – Movie Hub** is a modern movie, TV series, and anime discovery platform designed to provide a smooth and immersive streaming experience.

The platform allows users to explore trending content, discover new movies, watch TV series, and stream anime through multiple integrated streaming channels. The app focuses on a clean interface, responsive layout, and an intuitive video player experience.

The application integrates multiple APIs and streaming providers to ensure content availability and up-to-date recommendations.

Created by **Danny Daniels** under the **Danylix** brand.

## Features

### 🎬 Movie & TV Streaming
Users can stream movies and TV shows directly from integrated streaming sources through the custom video player.

### 📺 Multiple Streaming Channels
D.Verse integrates multiple streaming channels to improve playback reliability and availability.

- Channel 1 – VidSrc  
- Channel 2 – VidLink  
- Channel 3 – Reserved for future integration

### 🎌 Anime Integration
Anime content is powered using **MyAnimeList data through the Jikan API**, enabling the platform to provide accurate and updated anime information including:

- Trending anime
- Popular titles
- Seasonal releases
- Anime recommendations

Anime streaming uses **MAL IDs** to ensure compatibility with streaming providers.

### 🔍 Smart Search
Users can quickly search for:

- Movies
- TV Series
- Anime

The search system retrieves accurate metadata and relevant results across all content categories.

### 🎥 Custom Video Player
The application includes a custom video player overlay designed to improve the viewing experience while reducing intrusive interactions from embedded players.

Player capabilities include:

- Play / Pause
- Double-tap seek (forward and rewind)
- Fullscreen mode
- Mobile landscape playback
- Channel switching
- Sub / Dub toggle for anime

### ⭐ Content Discovery
The platform provides multiple discovery sections including:

- Trending movies
- Popular TV series
- Latest releases
- Seasonal anime
- Recommended titles

### 📱 Responsive UI
D.Verse is fully responsive and optimized for:

- Mobile devices
- Tablets
- Desktop screens

Poster grids and layout adapt dynamically depending on screen size.

### ⬇️ Download Feature
The **download feature is currently under development** and will be released in a future update.

## How can I edit this code?

There are several ways of editing the application.

### Use Lovable

Simply visit the Lovable project and start prompting.

Changes made through Lovable will automatically be committed to this repository.

### Use your preferred IDE

If you want to work locally using your own development environment, clone the repository and run the project.

The only requirement is having **Node.js and npm installed**.

Follow these steps:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Run the development server
npm run dev
```

### Edit files directly in GitHub

You can also edit files directly in GitHub:

- Navigate to the file
- Click the **Edit (pencil icon)** button
- Make your changes
- Commit the update

### Use GitHub Codespaces

You can run the project in **GitHub Codespaces**:

1. Go to the repository main page
2. Click **Code**
3. Open the **Codespaces** tab
4. Launch a new Codespace
5. Edit and run the project inside the cloud environment
